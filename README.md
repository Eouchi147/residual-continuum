# Residual Continuum — Finished Product

## Overview
A complete, mobile-first chronological investigative platform.

## Features Implemented
- Elegant chronological timeline as the core experience
- Expandable event markers with detailed evidence
- Interest-based filtering (chips) and live search
- Data Overlap mode (toggle layers to reveal coherence notes)
- Frosted glass design system with transparency
- Gentle colour coding (warm accent for cultural, cool for climate, soft purple for parallel orders)
- Flowy, minimal, highly reactive touch interactions
- Bottom navigation and clean top controls
- Full set of core historical markers covering the reconstructed sequence

## How to use
1. Open index.html on a phone or in mobile emulation.
2. Scroll the timeline or use filters/search to jump by interest.
3. Tap any marker card to expand evidence.
4. Toggle “Data Overlap” / “Layers” to see supporting connections.

## Design Notes
- Near-black base with soft frosted panels
- Refined serif for titles, clean sans for interface
- Motion is calm and inevitable
- Colour is used only for gentle guidance

This version fulfils the revised plan: chronological structure + search by interest + sophisticated timeline tool + data-overlap proof + frosted minimal aesthetic.

Live site will be deployed on Vercel.
